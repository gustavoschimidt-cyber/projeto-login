# Projeto Login - Atividade de Versionamento

Página de login com HTML, CSS e validação de campos em JavaScript,
versionada com Git e publicada no GitHub Pages.

## Funcionalidades
- Tela de login com mensagens de erro para campos vazios
- Painel principal com menu e boas-vindas (dashboard.html)
- Tela de cadastro de usuários (cadastro.html)

## Arquivos
- index.html: tela de login
- style.css: estilos das páginas
- script.js: validação dos campos
- dashboard.html: painel após o login
- cadastro.html: cadastro de novos usuários

## Branches
| Branch | Base | Finalidade |
|---|---|---|
| main | - | Código estável e publicado |
| develop | main | Desenvolvimento ativo |
| feature/validacao | develop | Validação de campos em JavaScript |
| feature/dashboard | develop | Criar painel principal |
| feature/cadastro-usuario | develop | Criar tela de cadastro |
| hotfix/erro-html | main | Corrigir erro estrutural no HTML |
| release/v1.1.0 | develop | Preparar nova versão para publicação |
